# Static Website Hosting Using Amazon S3

## Project Overview
This project demonstrates how to deploy and host a static website using Amazon Web Services (AWS) S3.

The project explores cloud storage, static website hosting, access permissions and basic cloud security configurations.

## Technologies Used
- Amazon Web Services (AWS)
- Amazon S3
- HTML5
- CSS3
- JavaScript
- GitHub

## Key Features
- Created an Amazon S3 bucket.
- Uploaded website files and assets.
- Configured static website hosting.
- Configured index and custom error documents.
- Implemented bucket policies and public read-only access.
- Tested website availability through the S3 website endpoint.

## Security Considerations
- Applied read-only access rather than write access.
- Reviewed S3 Block Public Access settings.
- Avoided storing AWS credentials in the repository.
